# copy-csv-text

A simple mobile-first web page that allows you to upload a CSV file, view its content, and copy the plain text to your clipboard.

## Features

- **CSV File Upload**: Tap to select or drag and drop a CSV file
- **Content Preview**: View the CSV content in a scrollable area
- **Copy to Clipboard**: One-tap button to copy the entire CSV content as plain text

## Usage

1. Open `index.html` in your browser
2. Tap the upload area or drag a CSV file onto it
3. View the CSV content displayed below
4. Tap "Copy to Clipboard" to copy the content

## Mobile First

The interface is designed for mobile devices with:
- Touch-friendly large tap targets
- Responsive layout
- Simple, clean design
